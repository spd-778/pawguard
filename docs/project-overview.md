# PawGuard Project Overview

PawGuard is a cloud-native animal safety and rescue platform built as a DevOps and SRE portfolio project.

The project demonstrates:

1. Containerization
2. Cloud deployment
3. CI/CD
4. Infrastructure monitoring
5. Observability
6. Alerting
7. Incident response
8. Failure testing
9. Recovery
10. Immutable deployments
11. Rollback

The goal is to demonstrate production-oriented DevOps and SRE engineering practices.
